# PDE 104220 Field Guide

A static, browser-based study guide for Partial Differential Equations. The site keeps the original field-guide content and features, including chapter navigation, formula search, progress tracking, and the exam map.

## Live site

https://thenotoriousteto.github.io/pde-field-guide/

## Update the site

Edit `index.html`, then commit and push changes to the `main` branch. GitHub Pages publishes the repository root.
